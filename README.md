# Customer Data Analysis

Customer data analysis using Python and Pandas — exploring income, spending patterns, and purchase channels across customer segments.

## What this project does
- Cleaned and analyzed customer marketing data (income, education, marital status, spending)
- Identified average income trends by education level
- Analyzed wine spending patterns across marital status groups
- Built visualizations to surface key insights

## Tools used
- Python
- Pandas
- Matplotlib

## Key Insights
- Widowed and divorced customers show the highest average wine spending
- Customers with graduate-level education tend to have higher average income

## How to run
1. Open the notebook in Google Colab
2. Run all cells to load, clean, and analyze the data
